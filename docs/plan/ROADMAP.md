# 一次交付一条可运行路径

从可运行的原版、工作台导航和多终端逐步扩展。阶段进入条件与退出证据见下表；验收结果见[台账](../agent/TASKS.md)。

| 阶段 | 所需输入 | 退出证据 |
|---|---|---|
| 0 · TermiRs 基线 | 可获取的固定上游提交、Rust 工具链 | SHA、LICENSE、原始构建、交互启动和现有测试记录；列出可复用模块、Tab 与平台限制。 |
| 1 · TUI 骨架 | 可运行基线、原有 SSH / SFTP 入口 | 键盘切换五个目的地；回到原入口可用；Core 文档能区分已实现接口与草案。 |
| 2 · 多终端与首次信任 | 页面与事件归属清楚、可用测试 SSH 服务 | 三个独立 SSH Session 同时收发；断开其一再连接，另两个继续收发。首次显示指纹，经确认才保存；同一地址换钥时拦截。 |
| 3 · rathole | 已验证的 SSH 生命周期、隔离的本机网关与开发机服务 | 通过受控的两段 SSH / rathole 链路访问测试设备；区分设备离线、重连、换钥和主动关闭。本轮跳过真实 VPS / 跨 NAT 验收。 |
| 4 · Files | 上游双栏入口、可用测试链路和临时目录 | 浏览、上传、下载、建目录、重命名、删除确认及取消；回读内容与原件一致。 |
| 5 · Sync | 两侧路径选择及可靠 SFTP、固定版本 rclone | 用同一 Profile 验收首次、增量、冲突、取消、断线及无效路径；目标独有文件保留。 |
| 6 · 本轮 Windows 发布候选 | 本地端到端路径齐备、Windows 测试机 | Windows Release 构建运行、身份与资源检查及实测报告。Linux 验收暂缓。 |

Phase 4 的本地 SFTP 夹具可以提前准备；发布验收仍按上表顺序，通过实际转发链路复测。一次性配对和自动/双向同步不占用本轮工期。
