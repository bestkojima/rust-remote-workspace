# 用两栏目录创建同步任务

在 **F2 Files** 打开保存的 SSH 设备。左栏进入要传的本地目录，右栏进入目标目录，然后按 **F7**。工作台会把这两个目录带入新 Profile；选目录和保存配置都不会复制文件。

在 Profile 中输入名字，检查设备和两条路径。用 **Tab** 换字段，用 **← / →** 选择上传或下载。排除规则以分号分隔，默认跳过 `.git`、`build`、`target` 和 `out`；例如追加 `*.tmp` 可以不复制临时文件。按 **Enter** 保存。

也可以直接在 **F3 Sync** 按 **n** 输入两侧的绝对路径。每个 Profile 独立保存设备、方向、目录与规则。在 Sync 按 **r** 可指定本机 **rclone 1.72.1** 的可执行文件；默认从 PATH 查找 `rclone`。

## 先确认远端目录由谁控制

在 F3 选 Profile，按 **Enter**。经 VPS 的设备先在 **F5 → T** 启动路由。首次连接先核对 SSH 指纹；保存公钥后，回到 F3 再按 Enter。

出现 **Authorize remote directory** 时，检查账号、端点和远端路径。SFTP 按路径打开文件；若其他进程可以在你核对后换掉目录或链接，预览里的路径就可能指向别处。请按实际条件选择：

- **e，仅此次。** 从预览到本次复制结束，你独占远端目录、它的祖先和任务暂存区，没有其他写者可替换它们。下一次预览仍要确认。
- **j，保存隔离范围。** 仅在 Profile 选择远端 `/` 时提供。管理员已经核实此 SFTP 账号被限制在恰好获准的根目录内，其他写者也不能接管工作台的 `.rrw-sync-*` 暂存区。保存的授权绑定设备、SSH 端点、账号、已核对的公钥及根目录；重启后仍可复用。在 Profile 列表按 **u** 即可撤销。

两项都无法确认，就按 **Esc** 退出。此时不会读取目录，也不会启动 rclone。服务器权限或隔离策略变化时，先撤销原有授权，再重新核实。

## 预览清单后，再决定写哪些文件

1. 目录范围确认后，工作台开始只读比较。有有效隔离授权的 Profile 会直接预览，实际连接仍验证 SSH 公钥。
2. 逐项查看 **NEW** 和 **KEEP**。NEW 会添加到目标；同名但内容有差异的 KEEP 默认保留。Windows 下载时，支持安全替换的冲突可用 **Space** 单独切为 **REPLACE**。上传遇到远端已有的同名文件会保留原件；要另存可回 Files 换名。
3. 按 **Enter** 核对来源、目标、文件数、替换数和精确字节数，再按小写 **y** 执行。选中至少 100 个文件或合计至少 100 MiB 时，确认页会提示中断文件重试时须从头传。单按 Enter 不会写入。预览后新增的源文件留到下一轮；已批准文件的版本如果变化，重新预览。

目标独有文件始终保留。扫描和复制时可切到其他页面，在 F3 按 **x / Esc** 取消。失败或取消后可重新预览：已传完且未变化的文件会跳过，中断的文件从头传。[上传与下载的断线实测](../testing/SYNC_ENGINE.md#断线后从哪里重传)

按 **h** 看所选 Profile 最近 12 条结果。删除 Profile 只删它的配置和日志，保留两侧目录。

## 复跑 Windows 交互验收

```powershell
cargo build --locked --bin rust-remote
uv run tools/smoke_sync.py target/debug/rust-remote.exe C:\tools\rclone-v1.72.1\rclone.exe
```

最后一个参数改成本机的 rclone 路径。脚本使用独立的 Windows 控制台、回环 SFTP 服务和临时目录，不需要已有设备或凭证。

**本机实测（2026-11-19）**：真实 F3 首次核对时拒绝，配置未变、服务端用户认证请求为零；同一地址换钥时拦截。F7 带入的目录和自定义排除规则重启后仍在。预览后添加的源文件没有被复制，远端已有的冲突文件和目标独有文件均保留。切换到下载后，选中的目标在确认前被修改，复制因此停止；重新预览并单项批准后，替换成功。扫描取消、第二个 Profile 目录无效及按 Profile 查询失败记录也已在原生界面跑通。

一次 Windows debug 采样中，本地源有 4 个文件（共 21 B，其中两个被排除），远端有 2 个文件（共 11 B），批准上传其中一个 7 B 文件。预览过程 88 次采样，工作台 / 子进程树最高观测工作集为 25.0 / 47.5 MiB；复制 90 次采样为 25.9 / 48.2 MiB。这组数值反映该小型夹具的运行开销。

**目录授权实测（2026-11-20）**：拒绝授权时，服务端未收到 SFTP 子系统请求，测试工具探针未被启动，配置字节不变。独占确认没有落盘，每轮预览都重新询问。绑定 `/` 的隔离授权在重启后可用；撤销后再次询问，改为子目录时也不会沿用旧授权。
