# 用可丢弃数据验收远程工作台

这里列验收方法和通过条件。已执行的平台、命令、失败及未测项记在 [CURRENT_STATE](../agent/CURRENT_STATE.md)。本机 SSH 服务、配置、known_hosts、双方文件目录与真实用户环境隔离。需要 VPS 的阶段再准备获授权的测试设备。

## 基线与页面

- 记录上游 SHA、OS/架构、Rust/Cargo 版本；原始提交先执行 `cargo build --locked`、`cargo test --locked`，在真实终端启动、检查第一屏并正常退出。fork 构建用同一工具链与 lockfile 比较。
- fork 测试时列出实际运行的入口；键盘走过五页并回到起点，检查当前页、焦点和底部动作是否一致。检查原本可用的连接、文件入口仍能进入。页面能打开与后端能工作分别记结果。

## Terminal

连同一个测试设备，顺序建 A、B、C 三个 Tab。各自设置不同的 shell 会话变量并打印；切回 A 时仍应读到 A 的值、看见 A 的历史。让 B 在后台输出，再回 B 检查输出保留且没有串进 A 或 C。发送 ANSI 颜色文本并调整窗口，验证实际终端显示及远端 PTY 尺寸。

结束 B 的远端 shell，检查断开状态并继续在 A 和 C 输入。重连 B，验证新 shell 可输入；再显式关闭 B，检查 A、C 和设备列表仍可用。旧连接晚到的输出不得写入重连后的 Tab。模型测试可以证明路由，三条真实 SSH 连接才满足三终端验收。

## Devices、隧道与身份

验证未知设备时，须从独立来源核对屏幕上的完整指纹。拒绝或保存失败时，配置保持不变，服务端用户认证请求数为零；确认后重启客户端，同钥可连。同一地址换钥须保留原记录，显示新旧指纹并中止连接。[本地设备复现命令与证据](HOST_KEY.md)。用无效登录密钥、超时及主动断开分别检查状态。用测试凭证确认配置、命令显示和日志不泄密。

本轮在[本机隔离链路](TUNNEL.md)验证开发机主动连入、家庭端 SSH 本地转发、隧道中断与恢复、主动停用。真实跨 NAT 实测本轮跳过；今后若部署到获授权的公网 VPS，另行核对防火墙及回环服务端口，确认目标 SSH 没有直接暴露。

## Files

用 Windows 含盘符与空格的本地目录、Linux 测试目录和中文文件名，键盘选路径、输入路径并逐级返回。两栏应显示正确侧的大小、修改时间和当前目录。上传已知文本，重命名，下载回另一临时目录并逐字节比较；新建测试子目录，删除时先取消检查仍在，再对预先授权的测试对象确认删除。取消大文件传输或让对端断开，检查进度停止、错误可见、其他 Tab 仍响应，并明确是否有未完成文件。

## Sync

两侧分别建临时根目录，源含小文件、大文件和排除项，目标放一个源端不存在的哨兵文件。按[复制规则](../design/SYNC_DESIGN.md)验证：

| 操作 | 必须观察到 |
|---|---|
| 首次 Dry Run，再取消；重新预览并确认 | 取消前后目标完全相同；确认后只出现获准文件，哨兵保留，无越界链接读写。 |
| 再跑一次；随后只改一个源文件 | 首次重跑无变化；下次仅列对应变化，覆盖须经确认。 |
| 两侧修改同一路径；预览后又改目标或新增源文件 | 显示具体冲突，可跳过；不执行过期覆盖或写入清单外文件。无法确保目标未变化时保留原件。 |
| 目标不可达、路径无效、传输中取消或断线 | 明确区分失败、取消和部分完成；子进程回收；重试从新预览开始。 |
| 修改排除规则，尝试链接到根外 | 配置重新加载后生效，预览与执行使用相同规则；根外文件内容不变。 |

## 资源与发布

Windows、Linux 各记录 OS 版本、CPU、RAM、Rust、上游与 fork 提交或工作树标识、构建模式、rathole/rclone 版本和文件集。固定终端大小、屏幕内容和采样窗口后，用同一环境报告：

- 从进程启动到首屏可输入的耗时（ms）；
- 空闲、连接一个和连接三个终端时的常驻内存（MiB）、观察窗口与空闲 CPU（%，注明分母）；
- 扫描与传输的文件数、总字节、最大单文件大小和峰值内存（MiB）。宿主和子进程分别列值；
- 重复开关会话和退出后有无残留进程、持续增长的缓存或日志。

有数据再设回归预算。交叉编译只覆盖编译环节，平台运行、实时传输与性能各自验收。
